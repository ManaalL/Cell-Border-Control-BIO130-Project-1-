# An Interactive Simulation of Membrane Transport in the Intestinal Epithelium

A self-paced review tool for introductory cell biology, built around the membrane transport topics in BIOL 130. The app follows one case study from start to finish: how an epithelial cell lining the small intestine absorbs glucose from a meal and passes it into the blood.

**Live site:** (https://manaall.github.io/Cell-Border-Control-BIO130-Project-1-/)

## Purpose

Membrane transport is usually taught as a set of separate mechanisms. This tool connects them through a single physiological example, so students can see how cell structure, membrane properties, gradients and transport proteins work together. Each concept is shown in a labelled figure, then tested through questions and simulations that respond to the student's choices.

## Structure

### Story modules

| Module | Topic |
|---|---|
| 1. Your cell | Organelles, cytoplasm and cytosol, the endomembrane system, and the route a new membrane protein takes from the nucleus to the plasma membrane |
| 2. The border | The phospholipid bilayer, the fluid mosaic model, integral, transmembrane and peripheral proteins, and selective permeability |
| 3. Water | Osmosis, osmotic pressure, and the effects of isotonic, hypotonic and hypertonic solutions on an animal cell |
| 4. Downhill | Passive transport: simple diffusion, and facilitated diffusion through channel and carrier proteins |
| 5. The pump | Primary active transport, the Na⁺/K⁺ pump, electrochemical gradients, and importers and exporters |
| 6. The glucose run | Secondary active transport, symporters and antiporters, and apical and basolateral membranes |
| 7. Bulk traffic | Exocytosis, endocytosis, phagocytosis, pinocytosis and receptor-mediated endocytosis |
| 8. Full meal | A cumulative assessment covering all previous modules |

Each module opens with an interactive figure. Clicking any structure shows its definition. Questions and simulations follow, and many ask the student to make a prediction before seeing the result.

### Independent study sections

- **Cell atlas:** a zoomable animal cell, a plant cell for comparison, and a membrane cross-section, with a quiz mode that hides the labels.
- **Checkpoint:** a practice mode in which molecules arrive with their size, polarity, charge and concentration gradient, and the student chooses the correct transport route.
- **Glossary:** every term used in the app, marked as not yet reviewed, reviewed or tested.

## Assessment

Scores are based on first-attempt accuracy. Students can retry any question after a wrong answer and read an explanation of why the answer was wrong, but only the first attempt counts toward the module score. Modules can be replayed to improve a personal best.

## Privacy

There are no accounts, and the app does not collect or send any personal data. Progress and scores are stored only in the student's own browser and can be cleared from the home page.

## Technical notes

The app is a single HTML file with no dependencies beyond Google Fonts. It runs in any modern browser and is designed primarily for laptop screens, with a layout that also works on phones.
